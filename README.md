
# 📊 E-Commerce Unit Economics & Profitability Dashboard (Excel)

## 📌 Описание проекта
Интерактивный дашборд юнит-экономики для селлеров маркетплейсов (Wildberries / Ozon). Проект решает ключевую проблему продавцов — отсутствие прозрачного учета чистой прибыли и маржинальности с учетом плавающих комиссий категорий и расходов на логистику.

---

## 🛠 Реализованный функционал & Стек

* **Инструменты:** MS Excel / Google Sheets, SQL (подготовка структуры данных).
* **Динамический справочник комиссий (`INDEX` + `MATCH`):** 
  Реализована автоматическая подтяжка комиссий маркетплейса в зависимости от категории товара с помощью формулы:
  ```excel
  =INDEX(N$2:N$7; MATCH(C2; M$2:M$7; 0))
